# Test Plan — OmniShop v2.8.0

## Scope
Registration, login, search, cart, checkout, payment, orders, refund and notifications.

## Test Levels
- API/integration
- UI smoke and critical-path E2E
- Database validation
- Regression
- Security
- Performance
- Accessibility/compatibility where applicable

## Entry Criteria
Build deployed, test environment available, critical requirements baselined, test data ready.

## Exit Criteria
Critical journeys pass, no unresolved release-blocking defects, regression target achieved, security/performance gates reviewed, residual risks accepted.

## Deliverables
Test evidence, defect report, execution metrics, risk update, release recommendation.
