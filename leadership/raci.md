# QA Leadership RACI

| Activity | QA Manager | QA Lead | QA Engineers | Product Owner | Engineering Manager | DevOps |
|---|---|---|---|---|---|---|
| QA strategy | A/R | C | C | C | C | C |
| Test planning | A | R | R | C | C | I |
| Risk assessment | A/R | R | C | C | C | C |
| Resource allocation | A/R | C | I | I | C | I |
| Defect triage | A | R | R | C | R | C |
| Automation strategy | A | R | R | I | C | C |
| Quality gate | A/R | R | C | C | C | C |
| Release recommendation | A/R | R | C | C | C | C |
| Production RCA | A | R | C | C | R | R |

**A = Accountable, R = Responsible, C = Consulted, I = Informed**
