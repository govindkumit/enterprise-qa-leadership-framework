# QA Manager Competency Scorecard

| Capability | Evidence in project |
|---|---|
| Strategy | QA strategy + test approach |
| Leadership | RACI + capacity plan |
| Stakeholder management | negotiation scenario + meeting rhythm |
| Risk management | release risk register |
| Delivery | sprint/release planning model |
| Technical depth | API/UI/CI/security/performance strategy |
| Governance | quality gate + traceability approach |
| Decision making | Go/No-Go recommendation |
| Incident leadership | production incident + RCA |
| Continuous improvement | corrective/preventive actions |
| AI readiness | AI QA direction in strategy |
