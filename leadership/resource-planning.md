# QA Resource Planning

| Area | Required | Available | Action |
|---|---:|---:|---|
| Functional QA | 3 | 2 | Prioritize critical journeys |
| Automation | 2 | 1 | Run existing smoke/regression suite |
| API/Integration | 1 | 1 | Protect payment/order flows |
| Security | 1 | 0.5 | Target critical APIs |
| Performance | 1 | 0.5 | Execute focused SLA baseline |

## Allocation Principles
1. Protect business-critical journeys.
2. Match specialist skills to highest-risk areas.
3. Automate repeatable regression.
4. Make capacity gaps visible early.
5. Document deferred scope and residual risk.
